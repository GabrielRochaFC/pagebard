# Changelog

All notable changes to Pagebard are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-11-22

First release.

### Added

- Real PDF pages, with the sentence being read highlighted on the page.
- Click a word to start there, double-click to read at once, drag to read only
  a passage; page range for the reading.
- Offline neural voices (Piper) with a voice manager to download and remove them.
- Play, pause, stop, and speed from 0.5× to 2.0×.
- Export to MP3.
- Text recognition (OCR) for scanned PDFs.
- Menus, keyboard shortcuts for everything, optional larger interface text,
  remembered preferences.
- Interface in English, Português (Brasil) and Español.
- Flatpak bundle.
